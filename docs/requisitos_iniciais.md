# Requisitos iniciais — legado

1. O sistema deve permitir vender produtos.
2. Deve suportar diferentes vendedores.
3. O pagamento deve ser seguro.
4. O frete deve ser rápido.
5. Deve permitir descontos.
6. O estoque deve estar correto.
7. O cliente deve receber notificações.
8. O sistema deve suportar alto volume.
9. Deve ser fácil integrar novas transportadoras.
10. O sistema deve ser simples de manter.

Os requisitos não possuem critérios de aceitação suficientes.
