# ShopSphere — Aula 14

## Tema
Strategy, Factory Method, Abstract Factory e Observer

## Situação do projeto
O ShopSphere possui artefatos e decisões legadas que podem estar incompletos ou inadequados ao conteúdo da aula. O aluno deve analisar antes de modificar.

## O que o aluno deve fazer
1. avaliar criticamente os quatro padrões legados;
2. aplicar Strategy em variação real pertinente;
3. usar Factory Method somente se a criação tiver variação justificável;
4. modelar famílias coerentes para Abstract Factory quando houver problema real;
5. permitir múltiplos interessados em eventos com Observer;
6. revisar os seis padrões com código, modelo e ADR.

## Dicas
- Padrão não é objetivo por si só.
- Explique quando a implementação inicial não caracteriza o padrão.

## Evidências mínimas
- Issue `Aula 14`;
- branch sugerida `aula-14`;
- commits explicativos;
- README/Markdown com problema observado, alteração realizada e critério de aceitação;
- evidência de compilação/teste quando houver código;
- PR ou revisão equivalente quando aplicável.

## Prazo operacional
O trabalho começa em sala e deve ser concluído até o início da aula seguinte, salvo orientação diferente do professor.
